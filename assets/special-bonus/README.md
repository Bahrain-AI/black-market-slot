# BLACK MARKET — Special Bonus Assets

Production-friendly vector derivatives for the newly designed Bonus Buy / Vault feature.

These assets preserve the BLACK MARKET visual language: matte black, champagne gold, ivory marble, smoked glass and deep burgundy. They are intentionally lightweight and browser-ready so the demo can use them without external runtime dependencies.

## Files

- `bonus-triggers.svg` — 8 special symbols: Scatter, Buyer, Wild Case, Multiplier Chip, Red Phone, Counterfeit Printer, Vault Key, EMP.
- `vault-modifiers.svg` — 8 persistent Vault modifiers: Counterfeit Printer, Golden Key, Inside Man, Black Card, EMP, Red Phone, Double Agent, Marked Lot.
- `bonus-ui.svg` — 6 presentation assets: Auction Hammer, Vault Door, Wild Transformation, Multiplier Increase, Cascade Win, Big Win.
- `manifest.json` — atlas cell mapping, names and intended behavior.

The full-resolution concept art generated during design remains archived outside the runtime bundle; this folder contains the web-ready derivatives intended for implementation in the browser prototype.

See [`../../BONUS-BUY.md`](../../BONUS-BUY.md) for feature behavior and math constraints.
