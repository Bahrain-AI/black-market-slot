# Asset Provenance, Ownership & Licensing

Status date: 2026-09-14. This document is part of the BLACK MARKET submission
package and must be read by the operator before upload.

## 1. How the assets were created

All artwork in this pack was generated with **ChatGPT (OpenAI LLM)** on behalf
of the project owner, then organized into the folders under `assets/`:

| Path | Contents | Status |
|---|---|---|
| `assets/black-market-complete-asset-pack/` | Branding marks, legacy-prototype PNGs, reference crops, 10 symbol `.webp` tiles, README | Prototype / placeholder quality |
| `assets/symbols/*.svg` | Fallback vector icons used by the prototype renderer | Placeholder |
| `assets/symbols/*.webp` | The 10 ChatGPT-generated tile crops copied from the asset pack — **now the runtime symbols** | In use |
| `assets/special-bonus/` | Bonus-trigger / vault-modifier / bonus-ui SVG concepts + manifest | Design reference, not wired to buy modes |
| `assets/anim-frames/` | Generated SVG keyframes (procedural placeholders) | Placeholder |
| `assets/animations/` | WebP sprite sheets + TexturePacker JSON produced by `pnpm gen:animations` | Placeholder, used as overlays |
| `assets/specs/mechanics-assets.md` | Production asset specification for the approval round | Spec |

## 2. Ownership / licensing statement

- The project owner prompted ChatGPT to generate the assets and therefore owns
  the generated outputs under the terms applicable to the tool used.
  **No third-party stock, licensed, or purchased artwork was used.**
- The owner warrants that all AI-generated material in this pack is original
  output they created via ChatGPT for this project and that they hold the
  rights to use, modify, and distribute it as part of the BLACK MARKET game.
- All AI-generated assets ship "as-is", prototype quality, and are **excluded
  from any certification or PAR claims** — they are visual placeholder
  material pending the production art pass.

## 3. Provenance risk to confirm before production

- `assets/black-market-complete-asset-pack/reference/black-market-reference.png`
  (and its `.webp` derivative) is a **user-supplied target image**, not an
  AI-generated asset. The 10 symbol `.webp` tiles and several pack elements
  were derived/cropped from it.
  → **Action required by the operator before production submission:**
  confirm the reference image is the owner's own original (or licensed)
  work. If it cannot be confirmed, source production symbols from scratch.

## 5. How to replace placeholders

1. Edit or replace the SVG keyframes in `assets/anim-frames/<name>/`.
2. Run `corepack pnpm gen:animations` to regenerate the sheets + JSON.
3. Run `corepack pnpm test` (schema test revalidates every sheet).
4. Re-run the tile package build and the packaging checks if sizes matter.
